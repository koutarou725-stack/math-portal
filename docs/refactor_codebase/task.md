# コードベースのリファクタリング（機能別分割）タスクリスト

## 目標
巨大化した `app.js`（10,000行超）と `style.css`（5,000行超）を、現代的なフロントエンド開発手法である「機能別モジュール化（Feature-based Design）」に基づき分割・整理する。これにより、機能間の干渉を防ぎ、保守性と拡張性を向上させる。

## タスク一覧
- [x] 1. 現状のコード構造の分析（依存関係、グローバル変数などの特定）
- [x] 2. ディレクトリ構造の設計と作成（`js/features/`, `js/core/` など）
- [x] 3. CSSの分割
  - [x] 3.1. ベーススタイル・リセットの抽出
  - [x] 3.2. コンポーネント別・機能別スタイルの抽出
  - [x] 3.3. 印刷専用スタイルの抽出
- [x] 4. JavaScriptの分割
  - [x] 4.1. データ定義（単元一覧など）の分離
  - [x] 4.2. 共通ユーティリティ（印刷処理など）の分離
  - [x] 4.3. 時間割機能のモジュール化
  - [x] 4.4. 授業プリント機能のモジュール化
  - [x] 4.5. 練習プリント機能のモジュール化
  - [x] 4.6. 小テスト機能のモジュール化
- [x] 5. HTMLからのモジュール読み込み設定（複数スクリプトでの読み込み）
- [x] 6. 動作確認・デバッグ（ブラウザ上でのリロードと動作確認をお願いします）
- [x] 7. 最終クリーンアップ（`app.legacy.js` と `style.legacy.css` としてバックアップ保存完了）
