# 授業プリント リッチエディタ＆ブロックリサイズ 実装計画

## 1. 目的
授業プリント画面（ワークシート工房）において、Googleサイトのように直感的で高度な編集機能を提供する。
現在のプレーンテキスト入力（`contenteditable`）を拡張し、以下の機能を実現する。
- 選択した文字の装飾（太字、サイズ変更、色変更など）
- ブロックの余白（解答スペース）のマウスドラッグによるサイズ変更

## 2. 実装アプローチ

### 2-1. フローティング・ツールバー（文字装飾）
文字を選択した際に、ポップアップでツールバーを表示する仕様（GoogleサイトやMediumのようなUI）を採用。
外部の重いエディタライブラリは導入せず、軽量で高速なブラウザ標準機能（`document.execCommand` および Selection API）をベースに実装する。

**実装するボタン:**
- 🅱️ 太字 (Bold)
- 🔠 文字サイズ拡大 (Font Size +)
- 🔡 文字サイズ縮小 (Font Size -)
- 🎨 文字色変更 (カラーパレット: 黒, 赤, 青, 緑, オレンジ など)
- 🧹 装飾クリア (Clear Formatting)

### 2-2. ブロックのリサイズ機能（ドラッグ操作）
問題ブロックの解答スペース（`.answer-space` 等）の下部に、「ドラッグ可能なハンドル」を追加する。

**操作フロー:**
1. リサイズハンドルを `mousedown`（掴む）
2. マウスを上下に `mousemove` することで、ブロックの高さを動的に変更
3. `mouseup`（離す）した時点で、その高さを `state.blocks[index].data.spaceHeight` に保存

## 3. 対象となるファイル
- **JS:** `js/features/class-print.js` （ツールバー制御、ドラッグ処理、HTMLレンダリングの更新）
- **CSS:** `css/features/class-print.css` （フローティングツールバー、カラーパレット、リサイズハンドルのデザイン）
- **CSS:** `css/print.css` （ツールバーやハンドルが印刷時に表示されないように制御）

## 4. UIデザイン案
- **ツールバー:** 黒または濃いグレーの半透明背景で、白抜きのアイコン。文字を選択した位置のすぐ上にふわっと現れるアニメーション。
- **カラーパレット:** ツールバーの「色」ボタンを押すと、よく使う5〜6色が丸いアイコンで表示される。
- **リサイズハンドル:** ブロック下部に現れる薄いグレーの横線と、3つのドット（グリップアイコン）。ホバーすると少し目立つ色になり、直感的に引っ張れることを示す。
